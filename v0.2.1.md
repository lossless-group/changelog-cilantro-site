## 🎉 New Features

### Changelog Preview Section Component

**Location:** `src/layouts/sections/ChangelogPreview--Default.astro`

A beautifully designed homepage section that surfaces the latest product updates, making changelog visibility a first-class citizen of the user experience.

**Key Features:**

#### Automatic Content Aggregation

Fetches and displays the 3 most recent changelog entries across all product collections:

```typescript
const allEntries = [...neoEntries, ...parsleeEntries, ...siteEntries]
  .filter(entry => entry.data.date_shipped)
  .sort((a, b) => {
    const dateA = a.data.date_shipped?.getTime() || 0;
    const dateB = b.data.date_shipped?.getTime() || 0;
    return dateB - dateA;
  })
  .slice(0, 3);
```

This ensures the homepage always shows the freshest updates without manual curation.

#### Responsive Card Grid Layout

Adapts to screen size for optimal readability:

```css
/* Mobile: Single column */
@media (max-width: 767px) {
  grid-template-columns: 1fr;
}

/* Tablet: Two columns */
@media (min-width: 768px) {
  grid-template-columns: repeat(2, 1fr);
}

/* Desktop: Three columns */
@media (min-width: 1024px) {
  grid-template-columns: repeat(3, 1fr);
}
```

#### Product-Specific Color Theming

Each changelog entry displays with its product's brand color:

| Product | Color | Badge Background | Hover Border |
|---------|-------|------------------|--------------|
| **Neo** | Purple (#8b5cf6) | `rgba(139, 92, 246, 0.1)` | `rgba(139, 92, 246, 0.3)` |

```astro

  {product.display}
</span>
```

#### Card Content Structure

Each changelog card displays rich metadata:

1. **Header Section:**
   - Product badge (colored, uppercase, bold)
   - Version badge (monospace font, gray background)

2. **Title Section:**
   - Clickable title linking to full entry
   - Hover effect changes color to teal

3. **Description Section:**
   - Lede text (if available) with muted color
   - Flexible height to accommodate varying content lengths

4. **Meta Section:**
   - Formatted date (e.g., "Oct 15, 2025")
   - Type label with semantic colors:
     - Major: Red (`#dc2626`)
     - Minor: Blue (`#2563eb`)
     - Patch: Gray (`#4b5563`)

5. **Footer Section:**
   - "View Details" link with product-specific color
   - Animated arrow icon on hover

### Date Formatting

Consistent date display across all changelog cards:

```typescript
function formatDate(date: Date | undefined): string {
  if (!date) return 'Recently';
  return new Intl.DateTimeFormat('en-US', {
    month: 'short',
    day: 'numeric',
    year: 'numeric'
  }).format(date);
}
```

**Output Examples:**
- `Oct 15, 2025`
- `Jan 1, 2026`
- `Recently` (fallback)

## 📊 User Experience Impact

### Discovery Path

**Before:**
1. User lands on homepage
2. Must navigate to `/changelog` link in footer
3. Views full changelog timeline

**After:**
1. User lands on homepage
2. Scrolls through sections
3. Encounters "What's New" section naturally
4. Views 3 latest updates immediately
5. **Option A:** Clicks card → Reads full entry
6. **Option B:** Clicks "View Full Changelog" → Explores timeline

### Engagement Opportunities

**Primary CTA:** Each card's "View Details" link
- Clear action ("View Details")
- Visual affordance (arrow icon)
- Product-colored for brand consistency

**Secondary CTA:** "View Full Changelog" button
- Prominent placement at section bottom
- Button styling (border, padding)
- Hover effects encourage interaction

### Information Architecture

**Metadata Hierarchy:**
1. **Product Badge** (most prominent) - Establishes context
2. **Version Badge** (secondary) - Technical identifier
3. **Title** (large, bold) - Main message
4. **Lede** (body text) - Supporting detail
5. **Date** (small) - Temporal context
6. **Type Label** (colored badge) - Classification

This hierarchy guides the eye from brand → content → metadata.
